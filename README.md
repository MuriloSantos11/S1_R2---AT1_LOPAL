Neste repositório possuo atividades realizadas no Flowgorithm, onde meu objetivo foi desenvolver as seguintes atividades no formato de fluxograma:

Exercício 1:
Criei um fluxograma que lê o nome de uma pessoa e exibe a mensagem: “Olá, [nome da pessoa]!”.

Exercício 2:
Criei um fluxograma que lê dois números, calcula a soma e exibe o resultado.

Exercício 3:
Criei um fluxograma que lê a idade de uma pessoa e verifica se ela é maior ou menor de idade. Se a idade for maior ou igual a 18, exibo “Maior de idade”; caso contrário, exibo “Menor de idade”.

Exercício 4:
Criei um fluxograma que lê um número e informa se ele é positivo, negativo ou zero.

Exercício 5:
Criei um fluxograma que lê duas notas, calcula a média e exibe o resultado final.
